# AGENTS.md

Guidance for Codex when working in this repository.

## Agent skills

### Issue tracker

GitHub Issues: issues and specs live in this repo's GitHub Issues (`MustacheXb/ReviewAgent`), managed via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five canonical roles, label string equal to role name (`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` at the repo root plus `docs/adr/`. See `docs/agents/domain.md`.
